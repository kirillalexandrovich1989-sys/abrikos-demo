# Источники компонентов и приёмов

## Кнопка с заливкой

CSS-приём с наклонной заливкой адаптирован из кнопки CristianMontoya98:
https://uiverse.io/CristianMontoya98/nasty-fish-9

Изменены цвета, размеры, состояния клавиатурного фокуса, область действия
селекторов и анимация. Используется только в `interactions.css`.

## Motion Primitives — референсы поведения

- https://motion-primitives.com/docs/animated-background — перемещение подложки
  между выбранными категориями.
- https://motion-primitives.com/docs/morphing-dialog — раскрытие изображения
  в отдельный просмотр, закрытие по Escape и возврат фокуса.

Эти взаимодействия написаны для проекта на обычном JavaScript, Web Animations
API и HTML dialog. React-компоненты и исходный код Motion Primitives не
скопированы; библиотека не установлена. При отключённых анимациях в системе
движение убирается. Новые фотографии не добавлены.
